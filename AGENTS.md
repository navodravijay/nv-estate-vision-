# NV. Estate Vision

This is a local Vite + vanilla TypeScript portfolio demo. Keep all developer, project and availability claims explicitly fictional. Do not commit, push or deploy without the user's explicit permission.

- Run `npm run typecheck`, `npm test` and `npm run build` after material changes. On restricted PowerShell systems use `npm.cmd`.
- `src/domain.ts` contains pure inventory, filter, preference validation and verified contact logic. Keep its tests meaningful.
- `src/config.ts` is public configuration, never a home for secrets. Contacts must remain disabled until genuinely verified.
- Do not collect personal information, add analytics, submit enquiries or claim a reservation. Only allowlisted preference fields may be saved locally.
- All architectural assets are original. Retain the independent concept disclosure and NV SHARP SOLUTIONS / Navod Ravindu Jayaweera credits.
- Preserve keyboard interaction, reduced motion, WebGL fallback and render-on-demand behavior. Cap renderer pixel ratio and dispose GPU resources.
- The map is an area overview with no fictional property marker. Keep attribution visible. Do not prefetch or cache OSM tiles outside normal browser caching; review the provider policy before changing map usage.
- Keep CSP in `index.html` and `public/_headers` aligned. Leaflet and GSAP require inline styles. New external hosts require a deliberate CSP update and documented purpose.
- Avoid `innerHTML` with dynamic content, `eval`, secrets, unnecessary packages or external media without documented rights.
